# 🚀 Beginner-Friendly CI/CD Pipeline with GitHub Actions & Pytest

Welcome! This repository is a hands-on, beginner-friendly example of an automated **CI/CD (Continuous Integration / Continuous Delivery)** pipeline built from scratch using **Python**, **`pytest`**, and **GitHub Actions**.

If you are learning software testing or test automation and want a simple, working template to understand how automated pipelines work, feel free to explore, fork, or reuse this setup!

---

## 📂 Project Structure

Software Testing Project
├── .github/
│   └── workflows/
│       └── pytest-pipeline.yml   # GitHub Actions CI/CD workflow configuration
├── calculator.py                 # Sample Python module (add, subtract, multiply, divide)
├── test_calculator.py            # Pytest unit tests validating the calculator functions
└── requirements.txt              # Project dependencies (pytest & pytest-html)
